## 2. Transcript sites

CODE (engine `withEngineMessageRow(Component, spec)`, engine.split unit 1778): one HOC for every transcript row (Code tab uses it through wrappers, Cowork through wrappers).
- Asks the hook for `t.inputOf(props)` = `{surface:"desktop", component, requestId, props}`; no ask when the session is not hooked, so the row stays native (`data-engine-native`, `display:contents`).
- While waiting for the first answer the native row is rendered hidden: style `{display:"contents",visibility:"hidden"}` (space reserved, nothing visible).
- After 5 s without an answer the row is shown as WITHHELD: `div[data-engine-withheld]` with the component re-rendered with text `"\u2026"` (`t.withText(a,"\u2026")`). This is what "withheld" rows show: the native row with its text replaced by an ellipsis.
- Drawn: `div[ref=frameRef style=frame hidden ...(data-engine-row-instance=requestId)] > div[ref=containerRef data-plugin-drawn="<Component>"]`, then the leaves (`engine slot`). Default frame is the frame helper with max height `none`; that helper gives `{contain:"paint",maxHeight:<max height>,minWidth:0,overflowY:"auto"}`; the hidden variant adds `display:"none"`.
- `frame` option used by hosts: Code tab and Cowork use the same frame: the 70vh frame plus `overflowX:"hidden", paddingInline:1, marginInline:-1` and a 1px custom property: max height 70vh with its own vertical scroll, 1 px side bleed so focus rings are not clipped. Where `frameInkOnly:true`, the frame applies only when the drawn tree has real ink (any Button/Input/Select/Svg/Client/Code, non-empty Markdown, non-empty text).
- `onlyRewrites:true` (ToolResult, UserMessage, CommandOutput): the tree is accepted only when it reparses (`t.parse(p.props)`) as the documented prop shape; if the mod returned a different shape the host logs "a ui.render hook answered a message row with props outside the documented shape; its tree was refused" (engine unit 1775) and the row stays native.
- `keepsPlace:true` (AskUserQuestion banner) keeps the native card slot while the drawing is an "engine placeholder".
- A row that returns nothing (`inputOf` null) is just native.
